

# **BULB GLOW USING AND LOGIC GATE**

## **1\. Aim**

To construct and demonstrate a basic digital logic circuit using an **AND gate** to control the operation of a bulb or LED.

## **2\. Problem Statement**

In many electronic control applications, the output needs to be activated only when **two specific conditions are satisfied simultaneously**.

## **3\. Proposed Solution**

An **AND gate** is implemented to control the bulb/LED. The output becomes HIGH only when both input signals are HIGH.

## **4\. Components Required**

* AND Gate IC – 7408  
* LED/Bulb  
* Resistor  
* Breadboard  
* Jumper wires  
* Battery/Power supply  
* Switches

## **5\. Circuit Working**

The AND gate consists of two inputs, **A and B**, and a single output. The LED/bulb turns ON only when both inputs receive a HIGH signal.

**Logic Operation:**

* A \= 1, B \= 1 → Output \= 1 → Bulb ON  
* A \= 0, B \= 0 → Output \= 0 → Bulb OFF  
* A \= 0, B \= 1 → Output \= 0 → Bulb OFF  
* A \= 1, B \= 0 → Output \= 0 → Bulb OFF

## **6\. Procedure**

1. Insert the 7408 AND gate IC onto the breadboard.  
2. Provide the required power supply connections to the IC.  
3. Connect two switches to the input terminals A and B.  
4. Connect the output terminal to the LED/bulb through a suitable resistor.  
5. Apply different combinations of HIGH and LOW inputs.  
6. Observe the LED/bulb response for each input combination.  
7. Verify the output with the AND gate truth table.

## **9\. Result**

The circuit was successfully constructed and tested. The LED/bulb illuminated only when **both inputs were HIGH**, confirming the operation of the AND logic gate.

The project successfully demonstrated the practical operation of an **AND gate**, in which the output is activated only when both input conditions are satisfied.
